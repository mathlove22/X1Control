# X1 Control 1.1.3

ONEXPLAYER X1 A / AMD Ryzen 7 8840U 전용 Windows 64비트 모니터링·팬 제어 프로그램입니다. .NET 런타임은 실행파일에 포함되어 있어 별도로 설치할 필요가 없습니다.

## 처음 실행하기

1. ZIP을 받았다면 **폴더 전체를 압축 해제**하세요.
2. `X1Control.exe`를 실행하세요. GPU와 사용률 등 읽을 수 있는 항목은 즉시 표시합니다.
3. CPU 온도·전력·팬 연결을 위해 **센서 드라이버 설치**를 누르고 공식 PawnIO 설치를 완료하세요. Windows 관리자 승인 창은 직접 처리해야 합니다.
4. 앱을 완전히 종료한 뒤 `X1Control.exe`를 우클릭하여 **관리자 권한으로 실행**하세요. 또는 드라이버 설치 뒤 앱의 **관리자로 다시 실행**을 사용하세요.
5. 팬을 조절할 때는 **OneXConsole와 Handheld Companion을 완전히 종료**하세요. 트레이와 관련 실행 프로세스까지 종료해야 합니다. 프로그램이 자동으로 다른 프로그램을 종료하지는 않습니다.
6. CPU 온도와 팬 연결 상태를 확인하고 원하는 모드를 고른 다음 **적용**을 누르세요. 모드 선택과 커브 편집은 먼저 미리보기로 동작합니다.

## 화면과 기능
- 하단 그래프와 CPU/GPU 요약 카드를 키워 수치가 잘리지 않도록 조정했습니다. 시스템 RAM은 장착 용량, 사용량, 사용 가능 총량, 여유 용량을 표시합니다. 현재 사용률 막대는 CPU/GPU 사용률과 같은 형태로 1초마다 갱신됩니다. VRAM은 시스템 RAM과 구분합니다. 전체 센서 진단은 요약 카드 아래에 배치했습니다.

- X1 화면에서 한눈에 보도록 대시보드와 팬 제어를 한 화면에 재배치했습니다. 창 크기는 현재 화면의 작업 영역에 맞춰 제한됩니다. 앱 아이콘과 트레이 아이콘도 포함했습니다.

- CPU/GPU 온도, 최고 CPU 코어 클럭, GPU 클럭, CPU/GPU 사용률, APU 패키지 전력, 팬 RPM과 출력률, 메모리 사용률, 배터리 잔량.
- 약 1초마다 갱신하는 그래프. 최근 최대 10분을 유지하며 시작 직후에는 시간축이 자동 확장됩니다.
- 센서가 없는 값은 `—`로 표시합니다. 실제 미수신 수치를 0°C나 0 RPM으로 만들지 않습니다.
- 기본 자동: 기기 펌웨어에 팬 제어를 맡깁니다. 앱을 새로 열었을 때 자동으로 소프트웨어 팬 제어를 시작하지 않습니다. 기존 EC 수동 설정이 감지되면 안내를 표시합니다.
- 저소음 / 균형 / 강력 냉각: CPU와 GPU 중 더 높은 온도를 기준으로 하는 자동 커브.
- 수동: 35~100%의 팬 출력률. RPM을 직접 지정하는 방식은 아닙니다.
- 사용자 커브: 40·50·60·70·80·90°C 지점의 출력을 편집합니다. 온도가 높아질수록 출력이 낮아지지 않도록 정규화합니다. 90°C 지점은 100%로 고정됩니다.
- 커브는 기본 설정의 미리보기입니다. 80°C 보호 출력과 90°C 비상 출력이 실제 제어에서 우선합니다.
- 트레이로 최소화, 항상 위 표시, CSV 저장, 전체 센서 목록과 JSON 진단 보고서.
- CSV에는 최근 최대 24시간의 **현재 실행 세션**이 저장됩니다. 앱을 닫기 전에 저장하세요. `APU_W`는 패키지 소비전력이며 TDP 설정값이 아닙니다.
- 사용자가 편집한 출력과 커브를 저장하되, 이전 소프트웨어 팬 모드는 재실행 시 자동 적용하지 않습니다.

## 팬 제어 보호 동작

- 정확히 ONE-NETBOOK / ONEXPLAYER X1 A / 8840U 조합인 경우에만 X1 EC 접근을 허용합니다.
- 최소 출력 35%, CPU 또는 GPU 80°C 이상에서는 최소 85%, 90°C 이상에서는 100%가 우선합니다. 수동 모드에도 적용됩니다. 이는 앱의 보수적인 제어 기준이며 제조사의 보증된 온도 한계를 의미하지 않습니다.
- 온도가 내려가면 5회 샘플을 기다린 뒤 회당 최대 4%씩 출력을 낮춥니다.
- CPU 온도 미수신·비정상 값·지연, UI 응답 중단, 충돌 프로그램 감지 시 앱이 소유한 제어를 기본 자동으로 돌리는 절차를 수행합니다.
- 쓰기 명령은 EC 재읽기로 확인합니다. 실패 시 제어를 중단하고 복귀를 시도합니다.
- 별도 감시 프로세스가 앱 종료와 약 5초 이상의 제어 신호 중단을 감지해 기본 자동 복귀를 시도합니다. 시스템 시계가 바뀌어도 경과시간 기준으로 판정합니다.
- 정상 종료·절전 진입에서 복귀를 시도합니다. 절전 해제 후에는 소프트웨어 팬 모드를 다시 적용해야 합니다.
- 감시 프로세스까지 함께 강제 종료되거나 드라이버·OS가 멈춘 경우 복귀를 보장할 수 없습니다. 오류 안내가 남으면 OneXConsole에서 기본 자동을 복원하거나 재부팅한 뒤 상태를 확인하세요.

## 이 PC에서 확인한 범위

**실제로 확인됨:** 기기 모델/CPU 식별, 관리자 권한 없는 상태에서 AMD ADLX로 Radeon 780M 온도·클럭·사용률 수신, CPU 사용률·메모리·배터리 표시, 그래프 렌더링, CSV 기록, 6가지 모드 미리보기와 커브 편집.

**자동 테스트:** 360개 검증. 과열/센서 결측/지연/잘못된 값/출력 범위/온도 하강 처리/커브 보간/명령 실패 후 복귀/감시 조건/시간 변경/내장 모듈 포함을 확인했습니다. 별도 UI 테스트에서 적용 전 미리보기가 하드웨어 제어로 이어지지 않는 것을 확인했습니다.

**아직 실기 검증하지 않음:** CPU 온도·전력·클럭의 관리자 센서 경로, EC 팬 RPM, 실제 팬 출력 변경, 하드웨어에서의 종료·절전·감시 프로세스 복귀. 제작 환경에 PawnIO가 설치되지 않았고 관리자 권한도 없어 이 항목의 실제 작동은 확인하지 못했습니다. 구현된 제어 코드가 있다는 것과 기기에서 검증됐다는 것을 구분해 주세요.

일반 센서 라이브러리가 이 PC의 GPU 온도를 반환하지 않아 설치된 AMD 드라이버의 ADLX 읽기 전용 인터페이스를 추가했습니다. 드라이버 업데이트나 BIOS/EC 버전 차이로 사용 가능한 센서가 달라질 수 있습니다.

## 연결이 안 될 때

1. 드라이버 설치 후 앱을 완전히 종료하고 관리자 권한으로 다시 실행했는지 확인합니다.
2. OneXConsole / Handheld Companion이 실행되어 있으면 종료합니다.
3. `전체 센서 / 연결 진단`을 펼쳐 상태를 확인하고 `진단 보고서 저장`으로 현재 값을 저장합니다.
4. X1 EC 응답이나 쓰기 확인 오류가 발생한 경우 커브 제어를 계속 재시도하지 말고 기본 자동 복귀 상태를 확인합니다.

앱 설정과 진단 로그는 `%LOCALAPPDATA%\X1Control`에 보관됩니다. 이 앱은 센서 기록을 외부로 전송하지 않습니다. 실행파일은 별도 코드 서명되지 않은 개인용 개발 빌드이며, 함께 제공한 PawnIO 설치파일은 공식 서명본입니다.

## 개발·검증 자료

`X1Control-source.zip`에 프로젝트와 테스트를 제공합니다. .NET 10 SDK에서 `build.ps1` 또는 `dotnet publish -c Release`로 빌드할 수 있습니다. 실행파일에 `--self-test`를 주면 하드웨어를 조절하지 않는 자동 테스트를 실행하고 `%LOCALAPPDATA%\X1Control\tests.txt`에 결과를 남깁니다.
