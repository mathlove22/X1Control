# X1 Control 1.1.3

- Changed the RAM card to a live usage bar matching the CPU and GPU cards.
- Reads system RAM sensors separately from GPU VRAM; shows installed RAM, sensor-reported used/available capacity, and free memory.
- Enlarged the temperature timeline while keeping the full dashboard visible on the X1 screen.
- Includes the source archive and third-party licensing/source information with the Windows release package.

## Compatibility

Windows x64. Designed for ONEXPLAYER X1 A with AMD Ryzen 7 8840U. Privileged CPU sensors and fan control require the official PawnIO driver and administrator rights. Close other EC fan-control software before applying a software fan mode.
